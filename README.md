# 🏡 Sweet Bea – My First Real-World Project  

Sweet Bea was a **specialized food service** that provided **high-quality products sourced from trusted local shops** for **house parties and family gatherings**. This project marked **my first real-world experience** in developing a **front-end website** for a business, solidifying my **skills in HTML, CSS, and structured design**.  

Though the business has since closed, this repository serves as an **archive** of its branding and service offerings.

## 📌 Project Highlights
- **Front-End Website Development** – Designed and built for customer engagement  
- **Branding & Visual Identity** – Created a professional and approachable digital presence  
- **Structured Layout & Styling** – Ensured accessibility and responsive design  

## 🚀 Technologies Used
- **HTML** – Structuring the website for clear navigation  
- **CSS** – Styling to enhance visual appeal and user experience  


## 🔗 Archive & Legacy
Sweet Bea represented **my first dive into professional web development**, helping me refine **design skills, branding strategies, and structured layouts**.
